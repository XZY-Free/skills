### Added

- **First skill: `opc-delivery`** — packages OPC-style delivery from rough
  business requests to PRD, UI design, frontend implementation, verification,
  and deployment evidence
  - Stage gates for requirements, solution design, MasterGo/Codify design,
    Magic restoration, frontend implementation, CI/CD deployment, and golden
    feature calibration
  - Keeps MasterGo's dual MCP servers (Codify + Magic) as design and D2C modules
  - References cover mcp-setup / intent-routing / requirements / solution /
    design / implementation / deployment / calibration / verification /
    troubleshooting / update-flow
  - Enterprise-grade output by default; opt-in quick-clone mode
  - evals.json covers both OPC delivery and MasterGo subflows
- **Repository metadata**: README.md / README.en.md (bilingual), LICENSE
  (Apache-2.0), SECURITY.md, CLAUDE.md, .gitignore
- **GitHub templates**: bug_report / mcp_error / feature_request / config +
  PR template
- **opc-delivery skill visual assets**: 5 SVGs (efficiency-comparison /
  how-it-works / quick-start / skill-structure / roadmap)
- **opc-delivery skill README**: bilingual, with embedded SVGs
- **Examples scaffolding**: `opc-delivery/examples/` with `_template/` directory;
  5 real-world walkthroughs landing in v0.2
- **CONTRIBUTING.md / CONTRIBUTING.en.md**: workflow, SKILL.md spec,
  commit / PR conventions
- **`scripts/`** repo validation scripts:
  - `check-links.py` — verifies internal markdown links + image paths
  - `check-svgs.py` — validates SVG XML well-formedness
  - `check-skill-frontmatter.py` — checks SKILL.md frontmatter
  - `check-evals.py` — validates evals.json schema
  - `run-evals.py` — generates BENCHMARK.md scaffold from evals.json
- **CI (`.github/workflows/ci.yml`)**: runs the four validation scripts on push / PR
- **opc-delivery/BENCHMARK.md**: scaffold generated by `run-evals.py`; awaits maintainer to fill measured numbers after the first complete benchmark pass
- **opc-delivery introduction site**: 8-slide landing page + solution doc deployed; README links to both entry points

### Known limitations

- No demo GIF / video yet (P0 scope is "looks professional"; demos defer to v0.2)
- No real examples yet (only `_template/`; v0.2 fills these in)
- BENCHMARK numbers not measured yet (scaffold landed; maintainer to fill after running the suite)
